# Combat reference values — aggregated

Medians across every measurement in the B1–B6 reports (a range counts as its midpoint for the median, its endpoints for min–max). n = number of measurements pooled. Where a source gave only peak force, energy was derived via impulse p = (2/π)·F·t (half-sine), E = p²/2m, with contact time t and effective mass m assumed per strike (punch 14 ms, kicks 10–15 ms, m 1.2–5 kg); see force_to_momentum_energy.md. All values from abstracts/snippets — see the per-topic reports for sources and verification flags.
